# Питомец привычек — Telegram Mini App

Трекер привычек в стиле тамагочи: отмечаешь привычки — питомец растёт от яйца до легенды, забрасываешь — грустит и через несколько дней погибает. Учебный проект.

## Как устроено

| Файл | Что внутри |
| --- | --- |
| `src/game.ts` | Вся логика питомца: опыт, сытость, настроение, стадии, смерть. Состояние пересчитывается из истории отметок |
| `src/game.test.ts` | Тесты логики (`npm test`) |
| `src/App.tsx` | Экраны: онбординг, питомец, привычки, прогресс, смерть |
| `src/Sprite.tsx` | Проигрывает спрайт-полосы по `src/manifest.json` |
| `src/storage.ts` | Сохранение: localStorage + Telegram CloudStorage (данные синхронизируются между устройствами) |
| `src/telegram.ts` | Обёртка над Telegram WebApp SDK: вибрация, цвета шапки |
| `public/pet/` | Готовые спрайты 128×128 |
| `art/` | Исходники спрайтов, промпты и скрипты Codex для перегенерации |
| `bot/` | Бот: `setup_bot.py` — кнопка меню и описание, `main.py` — ответ на /start |

Правила игры — в `RULES` в `src/game.ts`: +10 XP за привычку, бонус за серию дней, −10 сытости за каждый прошедший день и ещё −15, если за день ни одной отметки. Сытость 0 — питомец умирает. Яйцо не голодает.

## Запуск на компьютере

```
npm install
npm run dev
```

Откройте http://localhost:5173/?debug — внизу появятся кнопки отладки: «+1 день» (перемотка времени), день/ночь, сброс.

## Выкладка

Сайт и бот живут на сервере `129.101.120.201` в `/opt/habit-pet`: сайт отдаёт Caddy (HTTPS сам), бот — служба `habit-pet-bot`.
Обновить: `git push`, затем на сервере `bash /opt/habit-pet/deploy/update.sh`.

Адрес мини-аппа: https://129-101-120-201.sslip.io/ (тестовый режим — с `?debug` в конце).

## Бот

Секреты — в `bot/.env` (в git не попадает):

```
BOT_TOKEN=токен от @BotFather
WEBAPP_URL=https://129-101-120-201.sslip.io/  (с ?debug в конце — тестовый режим)
```

Один раз настроить кнопку меню и описание: `python bot/setup_bot.py`.
